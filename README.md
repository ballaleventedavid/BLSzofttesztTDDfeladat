# Arab–római konverter

## Működés

- Az arabicToRoman(number) az 1–3999 közötti egész számokat római számmá alakítja.
- Például 58 -> LVIII, 1994 -> MCMXCIV.
- Az érvénytelen bemeneteknél kivétel van

## Tesztelés
- Töltse le vagy klónozza a repositoryt.
- Nyissa meg az index.html fájlt egy böngészőben.
- Itt mind a 28 tesztnek sikeresnek kell lennie.
